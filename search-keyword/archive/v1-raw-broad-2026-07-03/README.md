# V1 Archive - Raw Broad Search

이 폴더는 V1 초광역 검색식을 보관한다.

- `semiconductor-ai-broad-patent-search-v1.md`: 누락 방지용으로 한영일중 키워드와 넓은 분류코드를 포함한 초안
- `semiconductor-ai-total-combined-query-v1.md`: V1 블록을 WIPS ON에 넣기 쉽게 결합한 전체 총합 검색식

V1은 A11 초기 탐색에는 유용했지만, 실제 WIPS ON 결과에서 배터리, 농업, 바이오, 일반 센서, 일반 기계 진단 문헌이 대량 유입되었다. 현재 대표 검색식은 상위 폴더의 `semiconductor-ai-total-combined-query.md`이며, 제목에 `V2`가 표시되어 있다.
